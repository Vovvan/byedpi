ByeDPI Go - Windows bundle
==========================

Локальный SOCKS5-прокси с обходом DPI (Go-порт ciadpi).

БЫСТРЫЙ СТАРТ
  1. Распакуйте архив в папку с путём без кириллицы, например C:\ByeDPI.
  2. Запустите youtube.bat.
     Прокси слушает только localhost: 127.0.0.1:1080.
     При запросе Windows Firewall разрешите доступ для частных сетей.
  3. Настройте браузер на SOCKS5 127.0.0.1:1080.

CHROME / EDGE
  Закройте браузер и запустите его с параметрами:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" ^
      --proxy-server="socks5://127.0.0.1:1080" --disable-quic
  Для Edge путь обычно:
    "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
  Можно создать ярлык с этими параметрами.

FIREFOX
  Настройки -> Сеть -> Прокси -> Ручная настройка:
    SOCKS-узел: 127.0.0.1, порт: 1080, SOCKS v5
    Включите "Прокси DNS при использовании SOCKS v5".
  Для стабильности отключите HTTP/3:
    about:config -> network.http.http3.enable = false

ПРОВЕРКА
  Откройте https://www.youtube.com/ и любое видео.
  В логе youtube-verbose.bat должны появляться новые соединения.

ЕСЛИ НЕ РАБОТАЕТ
  - Запустите youtube-verbose.bat и посмотрите сообщения об ошибках.
  - Убедитесь, что порт 1080 не занят: netstat -ano | findstr :1080
  - Попробуйте другие конфиги, например:
      ciadpi.exe -i 127.0.0.1 -p 1080 --split 1+s --disorder 1+s
      ciadpi.exe -i 127.0.0.1 -p 1080 --tlsrec 1+s --disorder 3+s
  - Один универсальный набор параметров невозможен: блокировки
    отличаются у разных провайдеров.

ПАРАМЕТРЫ
  Полный список: ciadpi.exe --help
  -x 1 или -x 2       - подробный лог (2 - максимальный)
  -p 1080             - порт SOCKS5
  -i 127.0.0.1        - слушать только локально
  --tlsrec 1+s        - разделение/перестановка ClientHello
  --disorder 1+s      - отправка частей в обратном порядке
  -D                  - запуск в фоне (без консоли)

ДОСТУП ИЗ ЛОКАЛЬНОЙ СЕТИ
  Уберите -i 127.0.0.1 из bat-файла, тогда прокси будет слушать все
  интерфейсы. Не делайте этого в недоверенных сетях: у прокси нет
  авторизации.

АВТОЗАПУСК
  Создайте ярлык на youtube.bat и положите его в папку автозагрузки:
  Win+R -> shell:startup
  Служба Windows (sc create) этой сборкой не поддерживается.

ПРИМЕЧАНИЯ
  - Это Go-порт; поведение и тайминги могут отличаться от оригинального ciadpi.
  - Исполняемый файл не подписан, поэтому SmartScreen может показать
    предупреждение.
  - Используйте только там, где это разрешено законом и правилами сети.
